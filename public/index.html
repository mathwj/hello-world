    How this works

    1. Read the brief. Your sentence becomes a structured plan: target titles, adjacent titles worth including, local-language variants, location radius, seniority bar and weighted must-haves.
    2. Source profiles. Each enabled source returns candidates, which are merged and de-duplicated.
    3. Analyse each one. Every profile is read against the plan — work history, education, tenure, trajectory — and each requirement gets a verdict backed by a quote from the profile.
    4. Rank and explain. You get a score, the evidence, the gaps, and a paragraph you can paste into a shortlist.

    Analysis is only as good as the data you feed it — always read the profile before contacting anyone. Scores are decision support, not decisions.
